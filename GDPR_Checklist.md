# GDPR Checklist for the HRSS Desk

> Practical working checklist, not legal advice. Follow your organisation's DPO guidance.

| Principle (GDPR Art. 5) | Desk practice | Where in this project |
|---|---|---|
| Lawfulness, fairness, transparency | Process data only for a valid HR purpose; tell employees how their data is used | `Purpose of Data Access` column |
| Purpose limitation | Use data only for the stated request; no reuse for other reasons | Dropdown of lawful purposes in `Lists` |
| Data minimisation | Share only what is needed; salary only on certificates to the employee | Tracker shows name only; salary kept on `Employees` / `Letter_Generator` |
| Accuracy | Verify against the HR system before issuing documents | SOP four-eyes check |
| Storage limitation | Follow retention schedule; flag leavers past retention for deletion/anonymisation | Process step - define in policy |
| Integrity & confidentiality | Send to verified recipients; password-protect/encrypt attachments; no personal data in chat or personal email | SOP controls |
| Accountability | Be able to show who accessed what, when, why | Request log (ID, date, assignee, purpose) |

## Daily habits
- [ ] Confirm recipient identity and email address before sending.
- [ ] Never forward documents to personal accounts.
- [ ] Lock screen when away; clear desk.
- [ ] Report suspected misdirected emails **immediately** - breach reporting clocks are short (72 hours to the regulator where required).
- [ ] Handle subject access, rectification or erasure requests by routing to the DPO/privacy team.
- [ ] Use synthetic data for training, demos and portfolios.
